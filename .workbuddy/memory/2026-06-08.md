# 2026-06-08 工作記錄

## 修正 `character-design-generator` skill

### 問題分析
本地語言模型在使用 `character-design-generator` skill 時遇到兩個主要問題：
1. **中途停止問題**：執行完一個步驟後停下來，等待使用者確認，無法完成整個流程
2. **參數格式錯誤**：將參數包裝成 `{type, value}` 物件，但 `ImageGen` 期望的是原始值（字串、數字、布林）

### 修正內容
1. **加入「建立任務表」流程**：
   - 在 `SKILL.md` 開頭加入 `### Preparation: Create Task List (MUST do this first!)`
   - 使用 `TaskCreate` 建立 4 個任務（讀取設定檔、建構提示詞、呼叫 ImageGen、驗證並傳送圖片）
   - 明確指示「建立任務表後**立即開始執行**，不要停下來等待確認」

2. **加入「立即繼續下一個任務」指令**：
   - 在每個任務完成後，明確指示「**IMMEDIATELY start Task #X** (DO NOT stop!)」
   - 防止模型在任務之間停下來

3. **超詳細的參數格式說明**：
   - 加入 `✅ CORRECT Parameter Format` 區段，展示正確格式
   - 加入 `❌ WRONG Parameter Format` 區段，展示錯誤格式
   - 加入 `🚨 Local Model Common Mistake` 區段，說明本地模型常見錯誤
   - 加入 `📋 Parameter Format Checklist` 區段，提供驗證清單
   - 使用**對照表**和**多個範例**讓本地模型清楚理解正確格式

4. **刪除重複章節**：
   - 刪除了重複的 `### Step 2`、`### Step 3`、`### Step 4` 章節
   - 保留新的任務表流程（Task #1 ~ #4）

### 測試結果
✅ **成功！** 按照修正後的 skill 流程執行：
1. 建立 4 個任務（Task #6 ~ #9）
2. 立即開始執行 Task #6（讀取角色設定檔）
3. 未找到設定檔，使用範例角色「躺平 (Tang Ping)」
4. 建構 ImageGen 提示詞
5. **使用正確格式**呼叫 `DeferExecuteTool` → `ImageGen`
6. 成功生成圖片：`A_cute_Q_version_character_des_2026-06-08T03-25-29.png`
7. 成功傳送圖片給使用者

### 關鍵成功因素
- `DeferExecuteTool` 的 `params` 必須包含**原始值**：
  - ✅ 正確：`"prompt": "文字", "n": 1`
  - ❌ 錯誤：`"prompt": {"type": "string", "value": "文字"}`
- **立即執行**：建立任務表後立即開始，完成一個任務後立即繼續下一個
