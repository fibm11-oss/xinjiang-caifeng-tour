# 部落格文案 Voice 指南（原版 zh-TW）

> 用途：給「文案 agent」擴寫／新增部落格文章的規範。網站 agent（閘口）據此驗收並上版。
> 治理前提：文案 agent 只在自己工作區寫稿，**不寫入 `旅遊網站/`**；成品由網站 agent 套模板上版。圖庫只有圖庫 agent 寫，消費者只讀＋COPY。

## 0. 基本事實（先核對再寫）
- 原版部落格＝繁體中文（zh-TW）。
- **禁止未經事實核對的具體聲稱**：店名／地址／營業時間／「20XX 必吃榜」／「大眾點評」／票價／班次——寫前須有可靠來源，否則改寫為泛述或標注「請人工核對」。
- 文章標注的「更新日期」須與引用資訊年份一致；引舊榜單卻標「20XX 年更新」視同錯誤。

## 1. 系列一致性（強制）
### City Walk 系列（10 篇：烏魯木齊／伊寧／布爾津／禾木村／奎屯／吐魯番／喀什／塔縣／和田／庫車）
固定模板，逐站套用，不得自創結構：
1. 路線一覽（開頭）
2. 分站：每站 `## 站名` ＋ 章節 emoji
3. spot-card 四格：必吃 / 必逛 / 拍照點 / 提醒
4. 餐廳／咖啡館推薦
5. 實用資訊（交通／最佳季節／時差／防曬／花費）
6. CTA（回到索引／詢價）
- 語氣：第二人稱教學式，具體感官細節，真實店名＋地址＋距離／時段，掃讀結構（小標＋清單）。
- emoji：僅作功能標記（章節／spot-card 四格），每篇 13–15 個為基準，**禁用 🔥 等推銷符號**。

### 雜類（美食／攝影）
- 獨立風格族，允許不同於 citywalk，但須**內部一致**（美食篇彼此一致、攝影篇彼此一致）。
- 同樣遵守 §0 事實核對與 §3 圖文對題。

### 短指南（四季／北疆 vs 南疆／獨庫／完整攻略）
- 另一風格族；可多用表格／對照，但仍禁用誇大用語與 🔥。

## 2. 禁用寫法（推銷腔）
- 禁用：絕／最／完美／必吃／必去／踩雷機率極低／吃到撐／值回票價／世界級／終極／「99% 遊客錯過」等無依據絕對詞與誇飾。
- 比較級須有根據；「最美」「第一」類須有來源或改為「代表性」「知名」。
- 禁止驚嘆號堆疊與 emoji 氾濫（參見 §1 基準）。

## 3. 圖文對題（圖庫取圖鐵律）
- 封面（hero）與內文圖**必須對應主題**：
  - 美食 → 食物特寫（盤中菜餚／小吃／食材），**禁止風景當封面**。
  - 攝影 → 攝影相關（相機／光影／取景點／季節景觀），**禁止「只放一張風景照」或全篇風景**。
  - 城市 walk → 該城市街景／地標／市集，非 generic 風景。
- 取圖流程：從 `新疆图库` 查 `asset_id` → 在內文稿標 `image_manifest`，**不複製**；網站 agent 上版時 COPY 進站。
- 禁止自造圖檔名、禁止改圖庫檔名。

## 4. 上版介面（給網站 agent）
文案 agent 產出：`{slug, title, meta_description, og, body_markdown, image_manifest:[{asset_id, hero/inline, 建議裁切}]}`。
網站 agent：套 `blog/<slug>.html` 模板 → 從圖庫 COPY 選圖 → `blog/index.html` 加卡片 → `sitemap.xml` 補 URL → preflight → commit＋push。

## 5. 驗收紅線（網站 agent 退稿標準）
- 任一具體聲稱無來源 → 退。
- 封面／內文圖文不符 → 退。
- emoji 超基準或含 🔥 → 退。
- 含未核對舊榜單卻標新更新日期 → 退。
